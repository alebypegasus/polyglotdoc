# Política de Segurança

## Versões Suportadas

Atualmente, aplicamos correções de segurança para as seguintes versões:

| Versão | Suportada          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Relatando uma Vulnerabilidade

Agradecemos a divulgação responsável de quaisquer problemas de segurança. Se você descobrir uma vulnerabilidade de segurança no **PolyGlotDoc AI**, por favor não abra uma issue pública.

Em vez disso, envie um e-mail para os mantenedores ou utilize o recurso **Security Advisories** do GitHub.

Nós nos comprometemos a:
1. Confirmar o recebimento do seu relatório em até 48 horas úteis.
2. Fornecer uma estimativa de tempo para a resolução da vulnerabilidade.
3. Notificar você assim que o patch for lançado e creditar sua contribuição de forma apropriada.
